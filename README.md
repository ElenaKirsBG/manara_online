# Офлайн-прототип приложения Таро Манара

Мобильный PWA-прототип: каталог 78 карт, четыре типа расклада и локальная история.

## Запуск

`index.html` можно открыть локально для просмотра интерфейса: карточные данные подключаются из `cards-bundle.js`. Для установки PWA и работы service worker откройте приложение через HTTPS или localhost. После первого открытия оболочка кэшируется, история хранится в браузере устройства.

## База карт

`cards-major-*.json` и `cards-*.json` — исходные файлы значений. После изменения этих файлов обновите объединённый `cards-bundle.js` командой `build-data.ps1` в PowerShell.

В базе сейчас есть значения всех 78 карт. Трактовки авторские и предназначены для размышления; они не устанавливают факты о другом человеке.
